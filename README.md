# 📋 Sistema de Relevamiento de Equipos

Aplicación web para registrar y gestionar equipos con sus certificados.

## Características

✅ **Ingreso de Equipos**
- Número de Serie
- Clase/Tipo de Equipo
- Estado del Certificado (Sí/No)

✅ **Gestión de Datos**
- Lista completa de equipos registrados
- Eliminar equipos
- Datos persistentes (localStorage)

✅ **Exportación**
- Exportar a archivo Excel (XLS)
- Incluye fecha de ingreso y exportación

## Cómo usar

1. Completa los campos del formulario
2. Haz clic en "Agregar Equipo"
3. Visualiza todos los equipos en la tabla
4. Exporta los datos a Excel cuando lo necesites

## Acceso

La aplicación está disponible en: https://henrysali.github.io/Audifon/

## Tecnologías

- HTML5
- CSS3
- JavaScript Vanilla
- LocalStorage para persistencia
- Exportación a Excel
