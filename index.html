Conectar con GitHub

Para sincronizar datos entre dispositivos, necesitas un Personal Access Token de GitHub.

¿Cómo obtener tu token?

  1. Ve a GitHub Settings → Tokens
  2. Haz clic en "Generate new token" (Personal access tokens)
  3. Dale el nombre "Audifon"
  4. Selecciona solo el permiso repo
  5. Copia el token generado
